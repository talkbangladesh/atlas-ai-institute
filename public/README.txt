Place static public brand and metadata asset files in this directory when provided by the owner:

- favicon.svg or favicon.ico (site browser tab icon; SVG preferred, fallback .ico)
- apple-touch-icon.png (180x180 PNG for iOS home screen bookmarks)
- logo.png (square/emblem or official Organization logo PNG used by Schema.org JSON-LD at https://atlasai.institute/logo.png)
- og-image.png (1200x630 PNG used for Open Graph and Twitter social share cards at https://atlasai.institute/og-image.png)

HTML link/meta tags and JSON-LD logo fields are automatically emitted when the corresponding file exists here and omitted when absent.
